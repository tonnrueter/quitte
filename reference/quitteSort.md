# Sorts a quitte object in a standardized way: model -\> scenario -\> variable -\> unit -\> region -\> period

Sorts a quitte object in a standardized way: model -\> scenario -\>
variable -\> unit -\> region -\> period

## Usage

``` r
quitteSort(x)
```

## Arguments

- x:

  anything with an as.quitte method (data.frame, quitte or magclass
  object, mif file, ...)

## Value

the sorted quitte object
